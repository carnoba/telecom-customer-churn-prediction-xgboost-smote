A professional-grade Machine Learning system designed to predict and mitigate customer attrition in the competitive telecom industry. This project achieves an **83% AUC-ROC** by implementing state-of-the-art predictive modeling, handling class imbalance with SMOTE, and extracting actionable business intelligence.

## 🚀 Strategic Overview

Customer churn is a billion-dollar challenge for telecom providers. This project utilizes the **XGBoost (Extreme Gradient Boosting)** framework to identify "at-risk" customers before they leave. Beyond prediction, the pipeline translates data into a **Marketing Retention Strategy**, allowing stakeholders to focus resources on the most critical customer segments.

## ✨ High-End Features

- **Advanced Data hygiene**: Automated handling of missing values, encoding categorical variables, and feature scaling.
- **Class Imbalance Solution**: Integrated **SMOTE (Synthetic Minority Over-sampling Technique)** to ensure the model learns from historical churn events effectively.
- **Model Optimization**: Hyperparameter tuning for XGBoost to maximize recall and precision for the churn class.
- **Interpretability**: Built-in feature importance analysis to show exactly *why* customers are leaving (e.g., Contract type, Monthly charges).
- **Business Reporting**: Includes a comprehensive PDF report outlining retention strategies for diverse customer tiers.

## 🛠 Tech Stack

- **ML Frameworks**: Scikit-learn, XGBoost, Imbalanced-learn (SMOTE)
- **Data Analysis**: Pandas, NumPy
- **Visualizations**: Seaborn, Matplotlib (Confusion Matrix, ROC Curve, Feature Importance)
- **Reporting**: PDF/Word (Business Documentation)
